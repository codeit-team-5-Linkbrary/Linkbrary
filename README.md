# 5팀 Linkbrary
- 배포 URL:https://linkbrary6-5.netlify.app/

## 프로젝트 소개
나만의 링크를 관리할 수 있는 서비스

아이디를 만들어 로그인을 하여 원하는 링크를 관리할 수 있습니다!
폴더를 만들어서 링크를 종류별로 나눌 수 있고 링크를 클릭하면 저장된 링크로 이동할 수 있습니다!

## 1.개발환경
  - **Next.js**: 파일기반 라우팅, 이미지 최적화등 기능을 가지고 있는 Next.js를 사용했습니다.
  - **module.css**: 컴포넌트별 고유한 클레스이름을 가질 수 있게 하였습니다.
  - **Axios**: HTTP 클라이언트 라이브러리인 Axios를 통해 백엔드 서비스와의 네트워크 통신을 처리했습니다.
  - **VSCode**: 코드 편집기로는 디버깅, 내장 Git, 구문 강조, 코드 완성등의 기능을가진 VSCode를 사용했습니다.
## 2. 협업 툴
  = **GitHub**: 코드 저장과 호스팅, 협업, 코드 리뷰등을 할 수 있는 GitHub를 사용했습니다.
  - **Discord**: 소통과 작업현황 공유 및 파일을 전달 할 수 있는 Discord를 사용했습니다.

## 5. 페이지 별 기능

### LandingPage

  - 프로젝트의 소개 페이지입니다.
  - 로고를 클릭하면 LandingPage로 이동하고 로그인 버튼을 누르면 로그인 페이지로 이동합니다.
  - 링크 추가하기를 눌렀을 때 로그인이 되어있다면 LinkPage로 이동하고 아니면 로그인 페이지로 이동합니다.

### LoginPage

  - 로그인 기능을 하는 페이지입니다.
  - 아이디와 비밀번호를 입력해 로그인을 할 수 있고, 없다면 회원가입 페이지로 이동할 수 있습니다.
  - 회원가입 페이지는 아이디, 비밀번호, 비밀번호확인, 이름을 받습니다.
  - 소셜 계정으로 로그인을 할 수 있습니다 (카카오, 구글)

### LinkPage

  - 사용자가 원하는 링크를 저장하는 페이지입니다.
  - 원하는 사이트의 주소를 입력해 링크를 카드형식으로 저장할 수 있습니다.
  - 카드를 카테고리 별로 저장할 수 있게 폴더를 만들 수 있습니다.
  - 만들어진 링크와 폴더를 삭제, 수정할 수 있고, 링크가 많아지면 페이지네이션으로 볼 수 있습니다.
  - 링크를 검색해 찾을 수 있고 만약 검색 결과가 없다면 저장된 링크가 없다는 메세지가 나옵니다.
  - 링크 카드에는 링크이름, 내용, 만들어진 날짜가 표시되고 즐겨찾기 표시를 누르면 즐겨찾기에 등록됩니다.
  - 링크 카드를 누르면 등록된 링크로 이동됩니다.

### Favorite

  - 사용자가 즐겨찾기에 등록한 링크들을 볼 수 있는 페이지입니다.
  - 즐겨찾기된 링크카드를 즐겨찾기 버튼을 한번 더 누르면 즐겨찾기 에서 삭제됩니다.

### 404Page

  - 잘못된 주소로 이동하면 나오는 페이지입니다.
  - 404페이지에 들어가게 되면 "페이지를 찾을 수 없습니다" 라는 메세지와 홈으로 돌아가기 버튼으로 LandingPage로 돌아갈 수 있습니다.

## 6. 팀회고

### Keep
  - 팀미팅에 잘 참여하고 팀 미팅 외적으로도 소통이 잘 된것 같다. 
  - 본인이 맡은 역할에 책인감을 갖고 최선을 다하였다.

### problem
  - 코드 컨벤션이 구체적이지 않아 코드를 통일시키기 어려웠다.
  - 아직 api와 js에 대한 이해가 부족해 코드 작성에 시간이 오래걸렸다.
  - 기능 개발에 시간이 오래걸려 일정이 밀렸고, 코드리뷰가 부족했다
  
### try
  - 가독성 좋은 코드를 작성해야겠다.
  - api와 js에 대한 공부가 더 필요할 것 같습니다.
  - 일정을 조금 더 꼼꼼하게 계획해야 할 것 같습니다.
